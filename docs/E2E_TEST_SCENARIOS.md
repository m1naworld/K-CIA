# K-CIA Lite — 통합 검증 시나리오 (Hands-on Playbook)

> **전제**: `docker-compose up` 으로 backend(8000) + frontend(3000) + DB 기동 완료.  
> 각 시나리오는 **실제 UI 조작 순서**로 기술. ✅ = 기대 결과(Pass 기준).

---

## 시나리오 A: 첫 진입 → 지도 탐색 → Hex 상세 (기본 플로우)

**목적**: M0~M3 핵심 기능 — 지도 로딩, 필터, Hex 클릭, 사이드바 카드 검증

| # | UI 조작 | 기대 결과 | 검증 포인트 |
|---|---------|-----------|------------|
| A1 | `http://localhost:3000` 접속 | 3D Hex 지도가 성수동 중심(127.055, 37.5435)으로 렌더링 | ✅ 지도 타일 표시 (Mapbox 또는 CARTO 폴백), ✅ Hex 기둥이 높이/색상 구분되어 보임, ✅ 렌더링 < 3초 |
| A2 | 좌측 필터 패널 확인 | 업종 셀렉트, 분기 셀렉트, 비교 모드 버튼, 소셜 토글 표시 | ✅ 업종 드롭다운에 100개 내외 업종 로드, ✅ "전체 업종" 기본 선택 |
| A3 | 업종 → `커피-음료` 선택 | 지도 Hex가 재로딩, 커피-음료 업종 기준 매출/유동 반영 | ✅ Hex 높이/색상 변화, ✅ 네트워크 탭에서 `hexagons?category=CS100001` 호출 확인 |
| A4 | 분기 → `2024년 4분기` 선택 | 해당 분기 데이터로 Hex 갱신 | ✅ Hex 높이/색상 변화 |
| A5 | 지도 위 **아무 Hex 클릭** | 우측 사이드바 슬라이드 오픈 + 상세 카드 표시 | ✅ 사이드바에 상권명 + as-of 배지 표시, ✅ 최소 5개 카드: 유동인구, 매출, 경쟁/점포, 성장추세, 리스크 |
| A6 | 사이드바 **유동인구 카드** 확인 | 총 유동인구(명), QoQ 증감률, 미니차트(최근 4분기) | ✅ 숫자가 0이 아닌 유효값, ✅ QoQ 화살표(↑/↓) + 백분율 |
| A7 | **매출 카드** 확인 | 총 매출액, 건당 매출, QoQ 성장률, 미니차트 | ✅ 금액 포맷(만원/억), ✅ as-of 배지에 분기 표시 |
| A8 | **경쟁/점포 카드** 확인 | 점포수, 개업/폐업수, 경쟁밀도 | ✅ 경쟁밀도(점포수/단위면적) 표시 |
| A9 | **성장추세 카드** 확인 | 매출/유동/점포 QoQ 변화율 | ✅ 양수=초록, 음수=빨강 색상 구분 |
| A10 | **리스크 카드** 확인 | 리스크 스코어(0~100), 게이지바, 심각도 배지, 원인 분해 차트 | ✅ 스코어 게이지 표시, ✅ 분해 항목 4개(폐업률/점포증가/매출감소/경쟁밀도) 바차트, ✅ 심각도 배지 색상(High=빨강/Medium=노랑/Low=초록) |
| A11 | 다른 Hex 클릭 | 사이드바 내용이 새 Hex 데이터로 갱신 | ✅ 상권명 변경, ✅ 모든 카드 수치 갱신 |
| A12 | 다크/라이트 모드 토글 (필터 패널 상단) | 전체 UI 테마 전환 | ✅ 지도 타일 + 패널 + 사이드바 + 챗봇 모두 테마 적용 |

## 시나리오 B: 시간대 분석 모드 (M10 피크타임)

**목적**: 시간대 모드 전환, TimeSlotCard, OperatingStrategyCard 검증

| # | UI 조작 | 기대 결과 | 검증 포인트 |
|---|---------|-----------|------------|
| B1 | 지도 상단 메트릭 토글에서 **「시간대」** 버튼 클릭 | Hex 색상이 피크타임 집중도 기준으로 변경 (파랑→빨강) | ✅ 기존 매출 증감 색상과 다른 색상 스케일, ✅ 범례가 "피크 시간대 집중도: 분산↔집중"으로 변경 |
| B2 | Hex에 마우스 올리기(호버) | 시간대 전용 툴팁 표시 | ✅ 피크 시간대명(예: "오후 14~17시"), ✅ 피크 비중(%), ✅ 평일/주말 비율(%) |
| B3 | 아무 Hex 클릭 → 사이드바 확인 | TimeSlotCard 표시 | ✅ **피크/오프피크 자동 분류**: 시간대별 바 + 피크=앰버, 오프피크=바이올렛, ✅ **요일×시간대 히트맵**: 7×6 그리드, 색상 대비 뚜렷(min-max 정규화), ✅ **평일 vs 주말**: 비율 프로그레스바 + 7요일 막대 차트(주말=오렌지) |
| B4 | 같은 사이드바에서 **OperatingStrategyCard** 확인 | 운영전략 카드 3개 섹션 표시 | ✅ **권장 영업시간 타임라인**: 24시간 바, 영업구간=초록, 피크=앰버 하이라이트, 개점/폐점 배지, ✅ **인력 스케줄**: 시간대별 staff_ratio 바 (피크 시간대가 1.0 이상), ✅ **매출 시뮬레이션**: 객단가(15,000원)/회전율(1.5)/좌석수(30) 기본값, 일/월 예상 매출 표시 |
| B5 | 매출 시뮬레이션에서 **객단가를 25000으로 변경** | 실시간 재계산 | ✅ 일/월 예상 매출 증가, ✅ "25000" 입력값 그대로 표시(0 안 잘림) |
| B6 | **좌석수를 50으로 변경** | 재계산 | ✅ 예상 매출 비례 증가 |
| B7 | 메트릭 토글 → **「매출」** 복귀 | Hex 색상이 매출 QoQ 기준으로 복귀 | ✅ 범례가 "매출 증감률" 관련으로 변경 |

## 시나리오 C: 리스크 분석 모드 (M11 경쟁과밀/폐업)

**목적**: 리스크 모드, RiskCard 게이지, 대안 구역 카드 검증

| # | UI 조작 | 기대 결과 | 검증 포인트 |
|---|---------|-----------|------------|
| C1 | 메트릭 토글 → **「리스크」** 버튼 클릭 | Hex 색상이 초록(Low)→노랑(Medium)→빨강(High)으로 변경 | ✅ 빨간색 Hex 존재(High risk), ✅ 범례 "Low→High" 그라데이션 |
| C2 | **빨간색(High risk) Hex** 클릭 | 사이드바 리스크 카드에 높은 스코어 표시 | ✅ 리스크 스코어 50+ (High 기준), ✅ 게이지바 빨간 영역, ✅ 심각도 배지 "고위험" (빨강) |
| C3 | 리스크 **원인 분해** 확인 | 4개 요소별 기여도 바차트 | ✅ 폐업률/점포증가율/매출감소/경쟁밀도 각각 기여도(%) 표시, ✅ 가장 큰 기여 요소가 시각적으로 명확 |
| C4 | **대안 구역 카드 (AlternativeAreasCard)** 확인 | 대안 2곳 표시 | ✅ 각 대안에 상권명, 리스크 스코어, 레벨 배지 표시, ✅ 현재 대비 리스크 개선폭(예: -20pt) 표시, ✅ 유동/매출/점포/폐업률 비교 그리드 |
| C5 | 대안 구역 카드에서 **첫 번째 대안 클릭** | 맵이 해당 Hex로 이동 + 사이드바 갱신 | ✅ 지도 뷰포트 이동, ✅ 사이드바에 새 Hex 상세, ✅ 리스크 스코어가 이전보다 낮음 |
| C6 | 업종 필터를 **「한식」**으로 변경 후 리스크 모드 유지 | 업종별 리스크 재계산 | ✅ Hex 색상 분포 변화 (업종에 따라 리스크 다름) |
| C7 | **초록색(Low risk) Hex** 클릭 | 낮은 리스크 스코어 | ✅ 스코어 < 40, ✅ 심각도 배지 "양호" (초록), ✅ 대안 구역이 없거나 비슷한 수준 |

## 시나리오 D: 분기 비교 모드 (M8)

**목적**: 비교 모드 토글, ComparisonCard 검증

| # | UI 조작 | 기대 결과 | 검증 포인트 |
|---|---------|-----------|------------|
| D1 | 필터 패널 → **「분기 비교 ON」** 클릭 | 비교 모드 활성화, Before/After 분기 셀렉트 표시 | ✅ 버튼 색상 변경(인디고), ✅ Before/After 분기 선택 UI, ✅ 업종 기준 토글(전체/선택) |
| D2 | Before = `2024년 3분기`, After = `2024년 4분기` 선택 | (비교 데이터 대기) | ✅ 셀렉트 값 반영 |
| D3 | 아무 Hex 클릭 | ComparisonCard 표시 (기존 카드 대신) | ✅ Before/After 스냅샷 (유동/매출/점포), ✅ 변화율 그리드 (QoQ %), ✅ 듀얼 바 차트 |
| D4 | 업종 기준 → **「선택 업종」** 토글 후 업종 변경 | 비교 데이터 자동 갱신 | ✅ 업종 필터에 따라 변화율 수치 갱신 |
| D5 | **「분기 비교 OFF」** 클릭 | 기본 모드로 복귀, 일반 사이드바 카드 표시 | ✅ Before/After UI 사라짐, ✅ 일반 카드(유동/매출/경쟁/성장/리스크) 표시 |

| E6 | **「소셜 트렌드 OFF」** 토글 | SocialBuzzCard 사라짐 | ✅ 사이드바에서 소셜 카드 미표시 |

## 시나리오 I: 엔드투엔드 — P1 예비 창업자 여정

**목적**: 실제 페르소나의 전체 사용 흐름을 시뮬레이션 (S1+S2+S5 통합)

### 배경

> 32세 예비 창업자가 성수동에서 디저트 카페를 열려고 한다. 입지 후보를 좁히고, 피크타임 운영전략을 세우고, 리스크를 점검하는 전체 여정.

| 단계 | UI 조작 | 확인 항목 |
|------|---------|----------|
| **1. 탐색** | 업종=`디저트/카페` 선택 → 3D 맵에서 높은 Hex 확인 | ✅ 매출 높은 구역이 높은 기둥, 성장하는 구역이 초록색 |
| **2. 후보 선정** | 높은 Hex 3곳을 순서대로 클릭하여 사이드바 카드 비교 | ✅ 각 Hex마다 유동/매출/경쟁 수치 비교 가능, ✅ as-of 배지로 데이터 시점 확인 |
| **3. 챗봇 질의** | `"여기 디저트 카페 차려도 될까? 초기 30평, 주말 집중"` | ✅ 근거 3개 + 리스크 2개 + 추천 2개 + 체크리스트, ✅ 선택 상권 컨텍스트 반영 |
| **4. 시간대 분석** | 메트릭 → 시간대 모드 전환 → 같은 Hex 클릭 | ✅ TimeSlotCard에서 피크=오후(14~17시 예상), ✅ OperatingStrategyCard에서 권장 영업시간 11:00~21:00 범위 |
| **5. 매출 시뮬** | 객단가=12000, 회전율=2.0, 좌석=20 입력 | ✅ 월 매출 예상치 계산 (예: ~2,000만원 내외), ✅ 시간대별 매출 breakdown |
| **6. 리스크 점검** | 메트릭 → 리스크 모드 → 같은 Hex 확인 | ✅ 리스크 스코어 확인, ✅ 원인 분해 (폐업률이 주요인이면 경고), ✅ 대안 2곳 제시 |
| **7. 대안 비교** | 대안 구역 클릭 → 리스크+매출 비교 | ✅ 대안이 원래보다 리스크 낮음, ✅ 유동/매출은 비슷하거나 나쁘지 않음 |
| **8. 챗봇 리스크** | `"이 구역 디저트 업종 폐업률 추세를 보여줘"` | ✅ 분기별 폐업률 데이터 응답 |
| **9. 분기 비교** | 비교 모드 ON → Q3 vs Q4 비교 | ✅ 매출/유동 변화율 확인, ✅ 계절성 파악 가능 |
| **10. 소셜 확인** | 소셜 ON → 해당 Hex 소셜 트렌드 확인 | ✅ 버즈량/감성/키워드 참고 가능 (데이터 있을 경우) |

## 시나리오 J: 에러/경계 조건 검증

**목적**: 비정상 상황에서의 graceful 처리 확인

| # | 상황 | 기대 결과 | 검증 포인트 |
|---|------|-----------|------------|
| J1 | 백엔드 미기동 상태에서 프론트엔드 접속 | 지도는 표시, Hex는 미로딩 | ✅ 에러 발생해도 앱 크래시 없음 (빈 상태) |

| J3 | 챗봇에 빈 문자열 전송 | 전송 차단 또는 안내 메시지 | ✅ 빈 요청 방지 |
